One photo upload feeds skin analysis and Fitzpatrick at the same time. YouCam charges only when a task succeeds, so our server waits for each task to finish. Results are saved by the photo's fingerprint (SHA-256), so the same photo never costs twice, and we keep scores only, never the photo.
